# 美术与一致性规范

美术规范与一致性

摄影级真实效果，近似真实摄影机拍出的北京现实主义都市短剧剧照。自然室内混合光、可信的老胡同灰砖、北方小店磨损痕迹、真实物品尺度，允许现实中的小瑕疵。NPC 必须各具面部辨识点：自然毛孔、浅痘印、不对称眉毛、眼周细纹、不过度统一的鼻嘴结构；禁止蜡像/塑料磨皮/通用网红模板脸、锐化过度、过度电影滤镜、假中文字及不合理手指。关键 Prompt 不只写 'realistic'，需结合角色独特特征与真实摄影灯光、镜头距离、装束以及场景布局。

采用两阶段：
1. 每名角色先生成 3 张候选，人工选定 `approved_reference_image`；核心 BG02 生成 2–3 张并锁定布局。候选数量需明确预算。
2. 后续所有人物及同一空间镜头必须引用已批准标准参考图，采用 Seedream 官方支持的图生图 / 多图参考能力，提示词和生成记录可追溯。角色参考图、场景参考图的路径保持不可变并记录版本。API 参考图并非 100% 锁脸：严审不合格图，必要时局部编辑，不要在无人审核条件下连锁生成几十张。

**模型策略：** 草稿默认选择支持的 Seedream flash（以实际控制台可用模型 ID 和当期价格为准），关键角色定稿/关键 CG 采用 pro。先查官方文档、以用户控制台可用真实模型标识调用，不能臆造 `model` 名字、价格或返回字段。若 pro/flash 价格关系与预期不同，可调整选择。程序应允许每类资产指定模型、解析度、预算上限和参考图数组。
