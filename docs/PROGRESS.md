## 阶段 3：离线 HTTP 集成与生产准备

新增真实本机 HTTP 测试服务，验证请求鉴权头、返回图片落盘、人工审核记录、批准图 base64 传入派生请求以及画廊生成。测试图只是临时 1px 传输夹具，不作为生产素材、不进入资产目录。测试过程不调用火山方舟、不产生生成费用。

新增资产库存／依赖检查与完整批准素材导出；批准素材不足 12 项时拒绝生产导出，避免占位图误入后续前端。

本地凭据已从用户提供的 RTF 导入 .env（权限 0600），被 Git 忽略，无凭据内容进入提交。本地未提供模型／Endpoint ID。真实单张生图、视觉人工审核和后续候选仍待模型与明确费用上限；此状态不等于目标全部完成。
